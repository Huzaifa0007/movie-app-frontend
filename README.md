# 🎬 Movie Application – Frontend

This repository contains the **frontend** of the Movie Application built using **React and Vite**.  
The application allows users to browse movies, search and filter them, and view detailed movie information.  
Admins can manage movies through add, edit, and delete functionality.

The UI is inspired by IMDb-style layouts and is fully responsive.

---

## 🚀 Tech Stack

- React (Vite)
- Material UI (MUI)
- React Router DOM
- Axios

---

## ✨ Features

- Browse movies with pagination
- Search movies by title
- Filter movies by:
  - Rating
  - Release Date
  - Duration
- Movie detail page with **“More like this”** section
- Admin role features:
  - Add movie
  - Edit movie
  - Delete movie
- JWT-based authentication
- Responsive and clean UI
